# 上下文读取与压缩策略

回答训练、减脂、饮食、增肌相关问题前，优先运行：

```bash
python scripts/fitness_coach.py build-context --topic general
```

## 默认压缩

- 永远包含：`profile.md` 的关键档案。
- 最近细节：最近 14 天每日记录。
- 趋势信息：最近 8 周周摘要、最近 3 个月月摘要。
- 长期事实：`data/memory/` 中和问题相关的要点。

## 主题偏向

- `training`：训练状态、动作、组数、RIR/RPE、疼痛、恢复。
- `diet`：热量、宏量、餐食、饥饿、外食、依从性。
- `weight-loss`：体重趋势、腰围、热量、睡眠、压力、饥饿。
- `general`：基础档案 + 最近综合状态。

不要把所有历史原文一次塞入上下文；先保留决策需要的事实、趋势和风险。
